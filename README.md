A single funny line, written by a program, for make.fun's "One Line, One Laugh" bounty — $2 in USDC.

`main.py` writes one self-contained joke to `/output/entry.txt`:

> My therapist asked what brings me joy. I said "cancelled plans" — she wrote it down.

A two-beat therapy joke: a wholesome setup, a subversive answer, then the therapist taking clinical notes. 84 characters, inside the 1–140 gate. See `candidates.md` for the ten candidates considered and the manual ranking against the kit's judge brief.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program self-checks the competition gate (UTF-8, 1–140 characters, not whitespace-only) before writing, and its output is byte-identical across runs.
